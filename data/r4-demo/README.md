## Reproduce and inspect

From the repository root:

```bash
uv run entropytrade research-and-test \
  --prompt 'Investigate Philadelphia forecast revisions and Chicago model disagreement; reject unsupported conclusions.' \
  --config configs/research/weather.json --offline \
  --output data/cache/r4-final-real --registry data/cache/r4-final.sqlite \
  --tracking data/cache/r4-final-mlflow

uv run entropytrade research-and-test \
  --prompt 'Investigate Philadelphia forecast revisions and model disagreement; compare hypotheses and retain negative controls.' \
  --offline --synthetic --days 240 \
  --output data/cache/r4-final-synthetic --registry data/cache/r4-final.sqlite \
  --tracking data/cache/r4-final-mlflow
```

A new agent UUID intentionally creates new search lineage. To reproduce frozen experiment
identities, use the same command/configuration with
`--research-run data/r4-demo/real/research/run.json` or
`--research-run data/r4-demo/synthetic/research/run.json`. The prompt is already preserved
in that audit. The generated feature/model inputs and implementation hashes must match.

- `real/` and `synthetic/`: complete research audits/criticism/specs and experiment
  result/ledger/report/trades/checksums. The synthetic feature manifest is retained.
- `models/` within each run: results/report and compact prediction Parquet. Original model
  checksums are retained as source inventories; joblib files and redundant JSONL are not
  copied into this evidence subset. Complete fitted models, JSONL/Parquet, SQLite and MLflow
  remain under the documented cache paths and are regenerated by the command.
- Root `checksums.json` enumerates exactly the frozen files; nested model checksums describe
  the complete original outputs, including omitted files. Never load arbitrary model binaries
  through research tools. No credentials, mutable databases or provider secrets are included.

The real source history is unchanged: zero certified historical forecast/scalar-label events,
no executable books/certified historical rules/fees. October weather receipts cannot backfill
September decisions. No additional real provider, authenticated feed or empirical profitability
verification was possible. See [operating guide](../../docs/experiments.md).
