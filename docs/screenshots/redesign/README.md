# Redesigned website — rendered screenshots

Captured by `frontend/browser/redesign.spec.cjs` in managed headless Chromium against a real
`entropytrade-web` localhost listener with a new, empty workspace (1440×900 unless noted).

**`demo-*` images show Demo Mode: fictional sample data generated in the browser.** They
are product previews, not market records, research results or trading performance. Every
demo page carries the Demo Mode banner, a "Demo data · simulated" chip and SIMULATED chart
watermarks. **`real-*` images show Real Mode** on an empty workspace, i.e. the honest
empty and unavailable states.
